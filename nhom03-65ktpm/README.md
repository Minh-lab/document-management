## Cấu trúc

```text
nhom03-65ktpm/
├── danhsachnhom.md   # Thông tin thành viên và phân công
```

## Chạy ứng dụng

```bash
cd nhom03-65ktpm/code
flutter pub get
flutter run            # chọn thiết bị/emulator
flutter test           # kiểm thử widget + kiến trúc
flutter build apk --debug
```

Cấu hình Firebase/Supabase xem tại `code/SETUP_GUIDE.md`.
